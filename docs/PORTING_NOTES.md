# Porting notes

1. Original NS1/NS2/NS3/RF entry modules and their required `src` modules are copied byte-for-byte into `src/skills/`. The package layout is retained to preserve `skills.*` cross-module imports. No unrelated business modules, test suites, cached bytecode or third-party implementation are vendored. `manifests/file_provenance.csv` records original workspace-relative paths and hashes.
2. Actual config snapshots are copied through structured YAML parsing. `project_root` becomes `../..` from each per-run config folder; input paths become explicit `data/` parameters and output paths `outputs/<run_key>/...`. Quantiles, seed values, class ratios, fixed IV breaks, RF parameters and split flags are retained. Source/target path mapping is in `manifests/input_path_mapping.csv`. Configs require explicit staging; they do not search for a latest run.
3. `scripts/run_sampling.py` uses the same corrected NS2 training-ID filtering performed in the final experiment wrapper: retain all 800 output positives, pass only the 560 recorded training positives into the original IV implementation. Hard-pool sampling calls the original module with the matching seed's baseline score configuration. Original raw NS2 code remains evidence and is not the final corrected entry point.
4. `scripts/run_model.py` invokes the original canonical combined stratified split, then checks exact saved IDs and order. The independent-negative-split intermediate wrapper is not used. Original RF training and prediction remain unchanged. No tuning or algorithmic repair was introduced during extraction.
5. Event/spatial bootstrap scripts retain the original RNG, iteration counts, pairing, estimator, quantiles and scale choices; only hardcoded workstation headers, IO paths and report destinations become CLI parameters. RNG/resampling code blocks are directly compared to their source. The raster evaluator extracts the existing lexsort/rank/capture/Lift/full-step-AUC/delta core, removing plotting and the hardcoded eight-raster mapping, with an explicit grid/domain check.
6. Saved sample IDs and row order are column-extracted, not regenerated. CSV serialization changes bytes but not included values. Source train/test hashes identify the original full private tables. `(run_key,sample_id)` is the public compound identity; raster-cell candidate pool IDs remain unavailable.
7. Result CSVs are copied with only absolute run/raster path columns removed. Raw logs and large objects are excluded. Original run metadata is reduced to relevant metrics/versions/PASS status; no complete private execution logs are redistributed. `manifests/runs.json` is an extraction, not a newly executed training record.
8. No original project file is edited by the release scripts. No scientific algorithm defect is silently corrected. The verification synthetic inputs exist only below ignored `outputs/` and are automatically removed after the test.
9. LICENSE deliberately grants no open-source rights pending author ownership/license selection. Dependency version records are preserved; a clean environment installation was not performed during extraction.
